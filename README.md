## 🧠 Scientific Methodologies Used
1. **Retrieval Practice:** Cold problem solving before reviewing notes.
2. **Distributed Practice:** Spaced repetition on +1, +3, +7, +14 days.
3. **Interleaved Learning:** Alternating Maths, Physics, Reasoning, and Data Interpretation.
4. **Desirable Difficulties:** Verifying mastery with unfamiliar question variants, not repeated memories.
5. **Metacognitive Error Tagging:** Diagnosing errors into 5 strict categories:
   - `Concept Gap`
   - `Calculation Error`
   - `Misread`
   - `Time-Management Failure`
   - `Bad Guess`
